## 스토브 가이드에 맞춘 점
- SDK 연동 대신 **DRM MAKER**: 스토브는 SDK를 붙이기 어려우면 DRM 없는 빌드를 '빌드 관리'로 올리면 DRM MAKER가 필수 SDK를 자동으로 붙인다고 안내함. Godot용 SDK가 없으므로 이 방식.
- DRM MAKER는 exe를 감싸므로 **게임 데이터(.pck)를 exe에 넣지 않고 옆에 따로** 둠(감싸기 뒤에도 데이터를 그대로 읽도록).
- 업로더 요구: 올릴 폴더에 실행 exe가 있어야 함 → `HansanDemo` 폴더 안 `HansanDemo.exe`. 설치 폴더 이름은 영어만 → `HansanDemo`.
- 경로 159자 제한 → 파일 이름 모두 짧은 영어. 폴더를 `C:\Hansan\HansanDemo` 처럼 짧은 곳에 두고 올릴 것.
- DRM MAKER 적용 확인: 스토브 런처로 설치한 폴더에 `BaseSDK.dll`, `DrmCheckerV3.dll`, `OwnershipSDK.dll`이 생기고, 런처 없이 exe를 직접 켜면 실행되지 않아야 함.

## 실행하지 못한 것 — 통과 처리하지 않음
- **Windows 실제 실행**: 작업 환경이 리눅스. Wine으로 켜 보았으나 Wine 자체가 시작 단계에서 멈춤(게임 이전 단계, 판단 불가).
- **스토브 런처 설치·실행 테스트(DRM MAKER 적용 확인)**: 개발자 계정에서 업로드 후 진행.
- **손으로 끝까지 하기(한국어·영어 1장 1~2막 완주)**: 회사 PC에서 확인 필요.
